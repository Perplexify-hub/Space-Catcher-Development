# Space Catcher

I am building a space game where a spaceship catches stars.

## What I have built

- A space-themed page with a neon cyan glow and animated thruster.
- A scoreboard showing score and lives.
- A game area with a spaceship and a star.
- A Start button.
- Styles that adjust to smaller browser windows.

The page is a screen design for now. The game is not playable yet.

## How to open the page

1. Download or clone this repository.
2. Open the project folder.
3. Double-click index.html to open it in a browser.

Keep style.css and Spaceship.png in the project folder.

## Project files

- index.html contains the page content.
- style.css controls the colours, sizes, spacing and layout.
- Spaceship.png contains the spaceship image used on the page.

## What I tested

When I made the browser window narrow, the title, text, and scoreboard boxes shrunk to fit without needing to scroll sideways. When I made it wide again, it returned to the full layout.

## What I learned

I learned how to style an arcade layout with CSS, add keyframe animations for the spaceship thrusters, and use media queries to make the page fit smaller screens.
